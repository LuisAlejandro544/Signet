feat(build): integrar empaquetado nativo sin extraccion y distribucion dedicada para emuladores PC

- Optimizacion de huella de instalacion en disco en dispositivos moviles:
  * Activacion de `useLegacyPackaging = false` (`extractNativeLibs = false`) en `app/build.gradle.kts` dentro del bloque `packaging.jniLibs`.
  * Habilita la lectura directa de librerias nativas `.so` (Room/SQLite y componentes NDK) directamente desde el archivo APK mediante `mmap` en Android 6.0+ (API 23+), eliminando la duplicacion y copia fisica en el directorio `/data/app/` del almacenamiento interno del telefono y reduciendo significativamente el peso de la app instalada.
  * Inyeccion de configuracion `resourceConfigurations += listOf("es", "en")` para filtrar traducciones automáticas no utilizadas en librerias AndroidX y Material 3, optimizando `resources.arsc`.

- Soporte de compilacion y distribucion independiente para emuladores de PC (x86 / x86_64):
  * Parametrizacion dinamica de `ndk.abiFilters` y filtros de exclusion de `jniLibs` mediante la propiedad Gradle `-PsignetTargetArch` (o variable de entorno `SIGNET_TARGET_ARCH`).
  * Generacion del binario principal de lanzamiento `Signet-${TAG}-release-signed.apk` preservando compatibilidad estricta con procesadores ARM de 64 bits (`arm64-v8a`) y 32 bits (`armeabi-v7a`) para maxima compatibilidad en telefonos moviles.
  * Generacion del paquete dedicado `Signet-${TAG}-emulator-x86-release-signed.apk` compilado exclusivamente con arquitecturas `x86_64` y `x86` para Android Studio Emulator, BlueStacks, LDPlayer y entornos CI/CD en PC.

- Actualizacion del workflow de CI/CD de GitHub Actions (`.github/workflows/build-release-apk.yml`):
  * Ejecucion secuencial de la compilacion y firmado tanto del APK para moviles como del APK dedicado para emuladores.
  * Generacion automatica de hashes de integridad criptografica SHA-256 independientes (`.sha256`) para cada variante de arquitectura.
  * Publicacion y adjunto de ambos paquetes en GitHub Releases / Pre-Releases con documentacion explicativa de arquitecturas.
  * Envio automatizado de ambos archivos a Telegram mediante MTProto / Bot API con sus respectivas huellas digitales y metadatos.

- Actualizacion de documentacion del proyecto:
  * Sincronizacion de `README.md`, `ROADMAP.md`, `STRUCTURE.md`, `AI_CONTEXT.md` y `Changelog-release.md` con las optimizaciones de almacenamiento y la matriz de distribucion de artefactos.
