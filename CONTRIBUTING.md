# 🤝 Directrices de Contribución: Signet

¡Gracias por tu interés en **Signet**!

---

## 📌 Estado Actual del Proyecto

**Signet** es un proyecto de código abierto publicado bajo la licencia **GNU General Public License v3.0 (GPL v3)**. 

En esta fase de desarrollo inicial, **el proyecto se encuentra bajo un desarrollo cerrado y focalizado por su autor principal, por lo que NO se aceptan contribuciones de código directas (Pull Requests ni parches externos) de terceros por el momento.**

---

## 🚫 ¿Por qué no se aceptan Pull Requests por ahora?

1. **Seguridad Criptográfica y Auditoría Centralizada**: Al tratarse de una herramienta que maneja generación de claves maestras, firmas digitales y generadores CSPRNG, mantener una única fuente de autoría facilita la verificación estricta de cada línea de código antes del lanzamiento público en tiendas y repositorios.
2. **Evolución del Roadmap**: La arquitectura modular y las fases del proyecto (Fase 1 a Fase 4) están siendo ejecutadas siguiendo una visión de producto específica.
3. **Consistencia Arquitectónica**: Queremos asegurar la estabilidad de la base de código, la persistencia en Room y las integraciones CI/CD antes de abrir la colaboración a la comunidad.

---

## 💡 ¿Cómo puedes ayudar?

Aunque no se aceptan Pull Requests de código por ahora, tu retroalimentación es muy valiosa:

* **Reportar Problemas (Issues)**: Si encuentras un fallo visual, un error en la generación criptográfica o un problema de compatibilidad con versiones de Android (Android 8 a Android 15), puedes abrir un Issue detallando el dispositivo y los pasos para reproducirlo.
* **Sugerencias de Funcionalidades**: Si tienes ideas para nuevos formatos o workflows de CI/CD, puedes compartirlas en la sección de discusiones o issues.
* **Probar la App**: Descargar y probar los APKs generados en plataformas como Uptodown, F-Droid o GitHub Releases.
